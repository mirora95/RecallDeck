# Security

RecallDeck is pre-release. Do not use early builds as the only copy of important study data. Local storage is not advertised as encrypted, and browser data can be cleared.

For a vulnerability, use GitHub's private vulnerability reporting if the repository exposes it. Otherwise contact the owner through the contact options on [her public profile](https://github.com/mirora95) and ask for a private reporting channel. Do not post secrets or personal learner data in public issues.

Ordinary bugs and synthetic-data reproduction cases can be reported in an issue. Include the app revision, platform, expected behavior and actual behavior.
