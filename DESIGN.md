# Shared foundation visual direction

Mode: Operate. A calm reading surface for a short study session, using a warm light background and dark green ink. The initial informational page uses a serif headline, system body text, generous readable spacing and a simple ruled definition list. No marketing metrics, fabricated learning statistics or ornamental motion.

Shared styling lives in `src/RecallDeck.UI/wwwroot/app.css`; both hosts load it through the Razor class-library asset path. Use semantic landmarks, a skip link, visible focus and a single-column release list below 640px. The 360px baseline must not overflow. Later app navigation is a separate backlog item.
