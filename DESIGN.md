# Shared foundation visual direction

Mode: Operate. A calm reading surface for a short study session, using a warm light background and dark green ink. The shared study pages use serif headlines, system body text, generous readable spacing, ruled lists and labeled forms. No marketing metrics, fabricated learning statistics or ornamental motion.

Shared styling lives in `src/RecallDeck.UI/wwwroot/app.css`; both hosts load it through the Razor class-library asset path. Use semantic landmarks, a skip link, visible focus and a single-column release list below 640px. The 360px baseline must not overflow. Shared navigation stays visible and wraps at narrow widths; the current page uses dark green fill and an underline. One shared layout owns the header, skip link, main landmark and recoverable page error state. Home due summaries, deck/card editing, reveal-first reviews, local progress and JSON backup/restore are working flows. Keep this visual direction when correcting factual copy; the [readiness record](docs/v0.1-readiness.md) describes current coverage.
