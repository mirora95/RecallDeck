Use .NET SDK **10.0.401** exactly (`global.json` disables roll-forward), Node **22+**, Python **3.11+** for scripts, and the [Android toolchain](android-toolchain.md): JDK 21, Android platform 36/build-tools 36.0.0 and the SDK's MAUI Android workload. MAUI Controls/Blazor WebView NuGet packages are pinned to **10.0.20**. Local acceptance used Node 24.14.1, JDK 21.0.11, Playwright Core 1.65.1, Chromium headless 151.0.7922.34 and an Android 17/API 37 x86_64 emulator. A tested runtime image is distinct from the Android compile target.

## Architecture decisions

- Android MAUI Blazor Hybrid and the Blazor WebAssembly PWA share one Razor UI assembly. Core owns validation, application operations and deterministic UTC scheduling without platform dependencies.
- `IStudyStore` defines coherent immutable reads and atomic writes. Android uses app-private SQLite; the web uses origin/profile-specific IndexedDB. There is no server database or account service.
- Reviews capture a due queue, reveal before rating and use a stable session-item identity for safe retries. Again resets to ten minutes; Remembered advances through 1/3/7/14/30 elapsed days, capped at level 5.
- JSON schema version 1 is the portable recovery boundary, with strict validation, a 10 MiB byte limit, preview counts and explicit replace-all confirmation. Test-only failure hosts are excluded from shipping registration.
- PWA assets cache after first online installation. Updates wait for all app tabs to close; the app warns the learner to save first and never forces activation/reload.

## Privacy and known limits

Study data stays in local browser storage or the Android app-private database. There are no accounts, telemetry, cloud sync, AI calls or paid integrations. Learner-entered sensitive text remains part of the data and exports. Local storage is not promised to be encrypted; external JSON backups are **unencrypted** and need protection wherever the learner saves or transfers them.

Browser data belongs to one origin and profile. Clearing site data, private browsing or storage eviction can remove it. Keep backups outside the app and verify that requested browser downloads saved; the app cannot confirm that the browser saved a file to disk. Android reports success only after the selected document stream closes. Replace-all restore overwrites all current decks, cards, schedules and history, including when a valid empty file is confirmed. Export first if current data matters. Large or escape-heavy datasets can exceed the 10 MiB export limit and fail visibly without truncation.

Home/Progress counts update on navigation, explicit **Refresh**, or Android resume. An open browser tab has no due-time timer or visibility refresh. History shows the latest 20 events and totals all currently retained events; deletion and restore change those totals. New origins/profiles do not share data. Offline PWA use needs a successful first online load and complete service-worker installation; production hosting would require HTTPS, correct MIME types and the origin root.

Coverage is limited to the named Chromium runs and an Android emulator using Debug packages. Destructive native recovery used the dedicated UiSmoke host linked to production UI, transport and SQLite; shipping checks preserved its baseline. Physical devices, TalkBack/screen-reader speech, every browser engine, every font scale, docked keyboard behavior, Release trimming/signing, power-loss, eviction and real disk exhaustion are not certified. Injected failures prove rollback paths, not actual exhausted hardware. No unresolved application defect was observed in the recorded paths; these limits are not a claim of universal correctness.

- Local decks and plain-text question/answer cards with validation, retained failed input and explicit deletion confirmation.
